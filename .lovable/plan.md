# Chat com o creator: como funciona hoje

Nada foi alterado. Este é só o resumo do comportamento atual.

## Quem pode conversar com o creator
- **Qualquer pessoa com conta e logada** pode abrir conversa e mandar mensagem para qualquer creator. Não precisa ser assinante.
- Quem não tem conta ou não está logado não acessa o chat.
- Ninguém conversa consigo mesmo.

## Única exceção que exige assinatura
- **Responder a um story** só funciona para quem tem assinatura ativa do creator.

## O que o creator pode fazer
- **Restringir** um fã: as mensagens desse fã param de aparecer para o creator (o fã continua conseguindo enviar, mas o creator não vê).
- **Silenciar**, **limpar** ou **apagar** a conversa, e **denunciar** o usuário.
- Configurar uma **mensagem de boas-vindas**.
- Mandar **mensagem paga**: mídia com preço. O fã só vê o conteúdo depois de pagar, mesmo sendo assinante.
- Ativar **envio pago de mídia pelo fã** (pedido de mídia), com faixa de preço mínima e máxima.
- **Videochamada paga**, com preço e duração definidos pelo creator.

## Resumo
| Situação | Pode mandar mensagem? |
|---|---|
| Não logado | Não |
| Logado, sem assinatura | Sim |
| Assinante | Sim (e pode responder stories) |
| Fã restringido | Envia, mas o creator não vê |

## Possível mudança (só se você quiser)
Se quiser que o chat seja uma vantagem de assinante, dá para adicionar uma opção para o creator escolher: "chat aberto para todos" ou "chat só para assinantes". Hoje isso não existe.
